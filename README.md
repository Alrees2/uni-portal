# ترشيحات القبول المسائي 2026–2027

موقع بحث بالاسم في قائمة الترشيحات المرفقة. يضم 716 طالباً موزعين على 13 قسماً. الأسماء والأقسام من الملف فقط، والنتيجة ترشيح للقبول حسب المصدر.

## النشر على Cloudflare Pages

- المستودع: `Alrees2/uni-portal`
- فرع الإنتاج: `main`
- Framework preset: `None`
- Build command: `exit 0`
- Build output directory: `dist`
- Root directory: اتركه فارغاً
- لا يحتاج إلى متغيرات بيئة أو مفاتيح أو قاعدة بيانات خارجية.

بعد ربط المستودع من Workers & Pages ثم Create application ثم Pages ثم Import an existing Git repository، تُنشر تغييرات main تلقائياً.

## البيانات

`dist/students.json` نسخة ثابتة من أسماء الطلاب وأقسامهم ونوع الدراسة في ملف «قبولات مرشحي المسائي 2026-2027.docx». لا يوجد اتصال بقاعدة تسجيل الطلبة أو كتابة فيها. رقم id داخلي للعرض، وليس رقم طلب أو رقماً امتحانياً. الملفات المنشورة ثابتة ومتاحة لزوار الموقع.

## التشغيل

انشر مجلد `dist` على أي استضافة ملفات ثابتة. البحث يدعم اختلاف الهمزات والتشكيل والمسافات، والفلترة حسب القسم وطباعة النتيجة.
