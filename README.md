# بوابة الاستعلام عن القبول المسائي 2026/2027

واجهة عربية لكلية البوليتكنك الحويجة، الجامعة التقنية الشمالية. تصميم أزرق وذهبي مع شعار الجامعة، بحث حي يدعم اختلاف الهمزات والمسافات وترتيب أجزاء الاسم، تصفية اختيارية حسب القسم، نسخ النتيجة وطباعتها. لا تعرض الواجهة إحصائيات عامة أو اسم ملف المصدر.

## النشر على Cloudflare Workers

إعدادات النشر موجودة في `wrangler.jsonc`، ويُنشر مجلد `dist` كما هو دون خطوة بناء.

| الإعداد | القيمة |
|---|---|
| Repository | `Alrees2/uni-portal` |
| Production branch | `main` |
| Project name | `uni-portal` |
| Build command | اتركه فارغاً |
| Deploy command | `npx wrangler deploy` |
| Preview command | `npx wrangler versions upload` |
| Root directory | اتركه فارغاً |

## البيانات والبحث

تستخدم النسخة `dist/students.json` المرفوع سابقاً، مع الحفاظ على بياناته دون تغيير. لا تستخدم Google Sheets ولا تتصل بقاعدة التسجيل أو تعدّلها. رقم `id` داخلي وليس رقم طلب أو رقماً امتحانياً. النتائج تمثل الترشيح للقبول، ويجب مطابقة الاسم الكامل واستكمال إجراءات التسجيل لدى الكلية.

## التشغيل والنشر الثابت

يمكن أيضاً نشر `dist` على Cloudflare Pages باختيار `None` و`exit 0` ومجلد إخراج `dist`. قدّم المجلد عبر خادم HTTP محلي عند التطوير حتى يعمل تحميل بيانات JSON. محتوى الملفات الثابتة قابل للوصول لدى زوار الاستضافة؛ إخفاء الإحصائيات تغيير في الواجهة.

## الهوية

الشعار المستخدم مستخرج من مستند القبولات المرفق. التذييل يحافظ على النص الذي طلبه المستخدم: تمت البرمجة من قبل أ. م. د. سهيل نجم شهاب التميمي.
